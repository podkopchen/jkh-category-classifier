# Category DeepPavlov v1.0

Локальный проект для проверки модели классификации обращений ЖКХ.

Модель принимает текст обращения из Excel-таблицы, определяет категорию проблемы и сравнивает результат с исходной категорией, указанной в таблице. 
Проект нужен для анализа качества классификации на реальных обращениях и поиска слабых мест модели.

---

## Что делает проект

Скрипт `example_predict_excel.py` выполняет полный цикл проверки:

1. Загружает Excel-файл с обращениями.
2. Берет текст из столбца `Описание проблемы`.
3. Загружает обученную модель классификации.
4. Предсказывает категорию обращения.
5. Сравнивает предсказание с исходной категорией из столбца `Категория`.
6. Сохраняет итоговые Excel-отчеты:
   - все предсказания;
   - только ошибки;
   - ошибки с высокой уверенностью;
   - матрицу ошибок;
   - classification report;
   - частые пары ошибок.
